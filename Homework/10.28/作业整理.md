# ICS 作业整理

## 第 9 讲作业题

### 4.47

本题先用指针访问实现冒泡排序，再将其翻译为 Y86-64 程序，并通过测试数组验证结果。

**A. 指针版 C 程序**

`p` 指向当前比较的左元素，`last` 指向本轮待排序部分的最后一个元素。每次比较 `*p` 和 `*(p + 1)`，若左边较大就交换。一轮结束后，当前最大值已到达 `last`，因此将 `last` 向前移动一个元素，再开始下一轮。

```c
#include <stdio.h>

void bubble_a(long *data, long count) {
    if (count < 2) {
        return;
    }

    long *p, *last;
    for (last = data + count - 1; last > data; last--) {
        for (p = data; p < last; p++) {
            if (*(p + 1) < *p) {
                long t = *(p + 1);
                *(p + 1) = *p;
                *p = t;
            }
        }
    }
}

long array[6] = {
    0xbca, 0xcba, 0xacb,
    0xcab, 0xabc, 0xbac
};

int main(void) {
    long count = (long)(sizeof(array) / sizeof(array[0]));
    bubble_a(array, count);
    for (long *p = array; p != array + count; ++p) {
        printf("%ld ", *p);
    }
    printf("\n");
    return 0;
}
```

入口处的 `count < 2` 判断使空数组和单元素数组直接返回，避免空数组时计算首元素之前的指针。测试时使用 `sizeof(array) / sizeof(array[0])` 获取元素个数。

程序输出为：

```text
2748 2763 2988 3018 3243 3258
```

对应的十六进制序列为 `0xabc, 0xacb, 0xbac, 0xbca, 0xcab, 0xcba`，按升序排列。

**B. Y86-64 程序**

使用 `%rdi` 传入数组首地址，`%rsi` 传入元素个数。主要寄存器的用途如下：

| 寄存器 | 用途 |
| --- | --- |
| `%rdi` | 数组首地址 `data` |
| `%rsi` | 初始化时由 `count` 转换为字节偏移 `8 * (count - 1)` |
| `%rax` | 待排序部分的末元素地址 `last` |
| `%rcx` | 当前元素地址 `p` |
| `%r8` | 右侧相邻元素的地址 `p + 1` |
| `%r9` | 右侧相邻元素的值 |
| `%rdx` | 临时计算、比较及保存左元素的值 |

```asm
    .pos 0
    irmovq stack, %rsp
    call main
    halt

    .align 8
array:
    .quad 0xbca
    .quad 0xcba
    .quad 0xacb
    .quad 0xcab
    .quad 0xabc
    .quad 0xbac

bubble_a:
    rrmovq %rdi, %rax
    irmovq $1, %rdx
    subq %rdx, %rsi
    addq %rsi, %rsi
    addq %rsi, %rsi
    addq %rsi, %rsi
    addq %rsi, %rax       # last = data + 8 * (count - 1)

L6:
    rrmovq %rdi, %rdx
    subq %rax, %rdx       # 比较 data - last
    jge L2               # data >= last，结束外层循环
    rrmovq %rdi, %rcx     # p = data

L5:
    rrmovq %rax, %rdx
    subq %rcx, %rdx       # 比较 last - p
    jle L3               # last <= p，结束本轮内层循环

    irmovq $8, %rdx
    rrmovq %rcx, %r8
    addq %rdx, %r8        # r8 = p + 1，即字节地址加 8
    mrmovq (%rcx), %rdx   # 左元素 *p
    mrmovq (%r8), %r9     # 右元素 *(p + 1)
    subq %r9, %rdx        # 左值 - 右值
    jle L4               # 左值 <= 右值，无需交换

    mrmovq (%rcx), %rdx   # 比较破坏了左值，重新读取
    rmmovq %r9, (%rcx)
    rmmovq %rdx, (%r8)

L4:
    irmovq $8, %rdx
    addq %rdx, %rcx       # 无论是否交换，都执行 p++
    jmp L5

L3:
    irmovq $8, %rdx
    subq %rdx, %rax       # last--，字节地址减 8
    jmp L6

L2:
    ret

main:
    irmovq array, %rdi
    irmovq $6, %rsi
    call bubble_a
    ret

    .pos 0x200
stack:
```

基本 Y86-64 没有乘法指令，因此初始化 `last` 时通过连续三次自身相加实现乘 8。C 中的指针加减一个 `long`，在这里对应字节地址加减 8。

**模拟器验证**

在 Linux 的 Arch Lab 目录中，将程序保存到 `misc/bubble.ys` 后运行：

```bash
./bin/ysim misc/bubble.ys --arch seq_std
```

本次运行的数组内存变化如下。模拟器按地址递增的字节顺序显示内容，Y86-64 采用小端存储，因此例如 `bc0a000000000000` 表示整数 `0xabc`。

| 地址 | 执行前的值 | 执行后的值 |
| --- | --- | --- |
| `0x0018` | `0xbca` | `0xabc` |
| `0x0020` | `0xcba` | `0xacb` |
| `0x0028` | `0xacb` | `0xbac` |
| `0x0030` | `0xcab` | `0xbca` |
| `0x0038` | `0xabc` | `0xcab` |
| `0x0040` | `0xbac` | `0xcba` |

六个元素已按升序排列，与 C 程序的结果一致。输出中 `0x01f0` 和 `0x01f8` 的变化来自两次 `call` 将返回地址写入栈中。

注：此工具包的汇编器使用 `L2`～`L6` 这类普通标签，标签定义和跳转目标均采用不带点的写法。

### 4.48

在 4.47 的基础上，将内层循环中的比较和交换改为条件传送。比较交换部分不使用跳转，并且只使用三条 `cmovge` 指令；内外层循环仍保留必要的控制跳转。

比较前，`%r9` 保存左元素，`%r10` 保存右元素。通过 `subq %r10, %rdx` 计算左值减右值，设置条件码。当左值大于或等于右值时，依次执行三次条件传送：

```asm
cmovge %r9, %r11      # 暂存原来的左元素
cmovge %r10, %r9      # 左位置准备写入原来的右元素
cmovge %r11, %r10     # 右位置准备写入原来的左元素
```

条件传送不改变条件码，因此三条指令使用同一次比较的结果。当左值小于右值时，三次传送均不执行，`%r9`、`%r10` 保持原值；之后统一写回内存即可。左右值相等时交换两个相同的值，也不影响结果。

完整程序如下：

```asm
    .pos 0
    irmovq stack, %rsp
    call main
    halt

    .align 8
array:
    .quad 0xbca
    .quad 0xcba
    .quad 0xacb
    .quad 0xcab
    .quad 0xabc
    .quad 0xbac

bubble_a:
    rrmovq %rdi, %rax
    irmovq $1, %rdx
    subq %rdx, %rsi
    addq %rsi, %rsi
    addq %rsi, %rsi
    addq %rsi, %rsi
    addq %rsi, %rax       # last = data + 8 * (count - 1)

L6:
    rrmovq %rdi, %rdx
    subq %rax, %rdx
    jge L2               # data >= last，结束外层循环
    rrmovq %rdi, %rcx     # p = data

L5:
    rrmovq %rax, %rdx
    subq %rcx, %rdx
    jle L3               # last <= p，结束本轮内层循环

    irmovq $8, %rdx
    rrmovq %rcx, %r8
    addq %rdx, %r8        # r8 = p + 1，即字节地址加 8
    mrmovq (%rcx), %rdx   # 左元素
    rrmovq %rdx, %r9      # 保存左元素，比较时不破坏原值
    mrmovq (%r8), %r10    # 右元素
    subq %r10, %rdx      # 左值 - 右值，设置条件码

    cmovge %r9, %r11
    cmovge %r10, %r9
    cmovge %r11, %r10
    rmmovq %r10, (%r8)    # 统一写回右元素
    rmmovq %r9, (%rcx)    # 统一写回左元素

    irmovq $8, %rdx
    addq %rdx, %rcx       # p++
    jmp L5

L3:
    irmovq $8, %rdx
    subq %rdx, %rax       # last--
    jmp L6

L2:
    ret

main:
    irmovq array, %rdi
    irmovq $6, %rsi
    call bubble_a
    ret

    .pos 0x200
stack:
```

在 Linux 的 Arch Lab 目录中，将该程序保存到 `misc/4.48.ys`，运行：

```bash
./bin/ysim misc/4.48.ys --arch seq_std
```

同一组六元素测试已在 Linux 模拟器中验证，排序结果为 `0xabc, 0xacb, 0xbac, 0xbca, 0xcab, 0xcba`，与 4.47 一致。

### 4.49

在 4.47 的基础上，用一次条件传送和异或运算实现内层循环的比较交换。比较交换部分没有跳转，并且只使用一条 `cmovge` 指令。

设左元素为 `a`，右元素为 `b`，先计算 `d = a ^ b`，再根据比较结果选取交换所需的值 `t`：

$$
t=\begin{cases}
a\mathbin{\oplus}b, & a\ge b,\\
0, & a<b.
\end{cases}
$$

随后将左右元素分别更新为 `a ^ t` 和 `b ^ t`：

| 比较结果 | `t` | 更新后的左值 | 更新后的右值 |
| --- | --- | --- | --- |
| `a < b`，保持原序 | `0` | `a ^ 0 = a` | `b ^ 0 = b` |
| `a >= b`，交换两值 | `a ^ b` | `a ^ (a ^ b) = b` | `b ^ (a ^ b) = a` |

相等时 `a ^ b = 0`，因此使用 `cmovge` 也不影响结果。

程序中 `%r9`、`%r10` 分别保存左右元素，`%r12` 保存 `a ^ b`，`%r11` 保存 `t`。异或计算在比较之前完成，之后执行 `subq` 设置条件码，再紧接唯一的一次条件传送，避免异或修改比较所需的条件码。

```asm
    .pos 0
    irmovq stack, %rsp
    call main
    halt

    .align 8
array:
    .quad 0xbca
    .quad 0xcba
    .quad 0xacb
    .quad 0xcab
    .quad 0xabc
    .quad 0xbac

bubble_a:
    rrmovq %rdi, %rax
    irmovq $1, %rdx
    subq %rdx, %rsi
    addq %rsi, %rsi
    addq %rsi, %rsi
    addq %rsi, %rsi
    addq %rsi, %rax       # last = data + 8 * (count - 1)

L6:
    rrmovq %rdi, %rdx
    subq %rax, %rdx
    jge L2               # data >= last，结束外层循环
    rrmovq %rdi, %rcx     # p = data

L5:
    rrmovq %rax, %rdx
    subq %rcx, %rdx
    jle L3               # last <= p，结束本轮内层循环

    irmovq $8, %rdx
    rrmovq %rcx, %r8
    addq %rdx, %r8        # r8 = p + 1，即字节地址加 8
    mrmovq (%rcx), %rdx   # 左元素 a
    rrmovq %rdx, %r9      # 保存 a
    mrmovq (%r8), %r10    # 右元素 b

    irmovq $0, %r11       # t = 0
    rrmovq %r10, %r12
    xorq %r9, %r12       # r12 = a ^ b
    subq %r10, %rdx      # a - b，设置条件码
    cmovge %r12, %r11    # a >= b 时，令 t = a ^ b
    xorq %r11, %r9       # a = a ^ t
    xorq %r11, %r10      # b = b ^ t

    rmmovq %r10, (%r8)
    rmmovq %r9, (%rcx)
    irmovq $8, %rdx
    addq %rdx, %rcx       # p++
    jmp L5

L3:
    irmovq $8, %rdx
    subq %rdx, %rax       # last--
    jmp L6

L2:
    ret

main:
    irmovq array, %rdi
    irmovq $6, %rsi
    call bubble_a
    ret

    .pos 0x200
stack:
```

在 Linux 的 Arch Lab 目录中，将该程序保存到 `misc/4.49.ys`，运行：

```bash
./bin/ysim misc/4.49.ys --arch seq_std
```

同一组六元素测试已在 Linux 模拟器中验证，排序结果为 `0xabc, 0xacb, 0xbac, 0xbca, 0xcab, 0xcba`，与 4.47、4.48 一致。

## 第 10 讲作业题

### 4.51

指令 `iaddq V, rB` 将立即数 `V` 与寄存器 `rB` 中的原值相加，并将结果写回同一寄存器，同时更新条件码。

该指令的取指过程与 `irmovq` 类似，执行阶段则进行加法运算。其指令编码占 10 字节：指令字节 1 字节、寄存器指示符字节 1 字节、立即数 8 字节。其中 `icode = 0xC`、`ifun = 0`，`rA = RNONE`，`rB` 指定参与加法并接收结果的寄存器。

各阶段的操作如下。`M_1[x]`、`M_8[x]` 分别表示从地址 `x` 读取 1 字节和 8 字节，`R[rB]` 表示编号为 `rB` 的寄存器中的值。

| 阶段 | 操作 |
| --- | --- |
| 取指 | `icode:ifun ← M_1[PC]`；`rA:rB ← M_1[PC + 1]`；`valC ← M_8[PC + 2]`；`valP ← PC + 10` |
| 译码 | `valB ← R[rB]`，读取目的寄存器的原值；不需要读取 `valA` |
| 执行 | `valE ← valB + valC`，并根据加法结果更新条件码 `ZF`、`SF`、`OF` |
| 访存 | 不读写数据内存 |
| 写回 | `R[rB] ← valE` |
| 更新 PC | `PC ← valP` |

这里 `valC` 是取指阶段读出的立即数，`valB` 是译码阶段读出的寄存器原值。执行阶段选择 `valC` 和 `valB` 作为 ALU 的两个输入，执行加法；ALU 的 A 输入端使用 `valC`，不代表必须使用信号 `valA`。
