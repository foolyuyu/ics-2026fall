# ICS 作业整理

## 第 7 讲作业题

### 3.66

根据汇编代码，可以确定两个宏定义为：

```c
#define NR(n) (3 * (n))
#define NC(n) (4 * (n) + 1)

long sum_col(long n, long A[NR(n)][NC(n)], long j) {
    long i;
    long result = 0;
    for (i = 0; i < NR(n); i++) {
        result += A[i][j];
    }
    return result;
}
```

这道题的关键是理解二维数组的内存布局：各行依次连续存储，可以看成按行展开的一维数组。`NR(n)` 表示行数，`NC(n)` 表示列数。函数计算第 `j` 列的和，因此每次迭代都需要从 `A[i][j]` 移动到下一行的 `A[i + 1][j]`。

在题目的 x86-64 环境中，`sizeof(long) = 8`。相邻两行同一列的元素之间相隔 `NC(n)` 个 `long`，也就是 `NC(n) * 8` 字节。元素地址满足：

$$
\operatorname{addr}(A[i][j])
=\operatorname{addr}(A)+(i\cdot NC(n)+j)\times8.
$$

汇编中的 `%r8` 保存每次移动到下一行所需增加的字节数：

```asm
leaq 1(,%rdi,4), %r8   # %r8 = 4*n + 1，此时 %rdi = n
salq $3, %r8           # %r8 = (4*n + 1) * 8
```

循环中将 `%r8` 加到当前元素指针，就可以访问下一行同一列的元素。因此：

$$
NC(n)=4n+1.
$$

`NR(n)` 则可以从循环的终止条件中确定。汇编先计算 `3*n`，再将其放入 `%rdi`：

```asm
leaq (%rdi,%rdi,2), %rax   # %rax = n + 2*n = 3*n
movq %rax, %rdi           # %rdi = 3*n，作为循环上界
```

进入循环后，`%rdx` 保存计数变量 `i`，每次迭代增加 1。循环末尾的比较：

```asm
cmpq %rdi, %rdx           # 比较 i 与 3*n（设置 %rdx - %rdi 的条件码）
```

配合后续的条件跳转，实现 `i < NR(n)` 的判断，因此 `%rdi` 中的 `3*n` 就是行数：

$$
NR(n)=3n.
$$

### 3.67

本题考察结构体参数的栈上传递，以及通过调用者预留的空间返回结构体。两个结构体均占 24 字节：

```c
typedef struct {
    long a[2];
    long *p;
} strA;

typedef struct {
    long b[2];
    long q;
} strB;
```

下面以 `eval` 执行 `subq $104, %rsp` 后、调用 `process` 前的栈指针为基准，记为 `R`。`process` 返回后，`eval` 的 `%rsp` 也恢复为 `R`。

**A. 调用 `process` 前的栈布局**

| 相对 `R` 的偏移（字节） | 内容 |
| ---: | --- |
| 0～7 | `s.a[0] = x` |
| 8～15 | `s.a[1] = y` |
| 16～23 | `s.p = &z = R + 24` |
| 24～31 | 局部变量 `z` |
| 32～63 | 此处汇编未使用的空间 |
| 64～87 | 为返回结构体 `r` 预留的空间，此时尚未写入 |
| 88～103 | 此处汇编未使用的空间 |
| 104～111 | `eval` 返回到其调用者的返回地址 |

传入 `process` 的结构体 `s` 存放在栈上的参数区域，字段依次是 `x`、`y`、`&z`。

**B. 传入 `%rdi` 的值及作用**

```asm
leaq 64(%rsp), %rdi
call process
```

`%rdi` 中保存 `R + 64`，即返回结构体 `r` 的存储空间地址。这是编译器传递的隐藏返回指针，供 `process` 写入返回值；它不是结构体参数 `s` 的地址。

**C. `process` 如何访问结构体参数 `s`**

执行 `call` 时，处理器把返回到 `eval` 的地址压入栈中，占 8 字节。由于 `process` 没有进一步调整栈指针，进入该函数时 `%rsp = R - 8`。因此同一组参数在 `process` 中的偏移增加了 8：

| `process` 中的地址 | 对应内容 |
| --- | --- |
| `(%rsp)` | 返回到 `eval` 的地址 |
| `8(%rsp)` | `s.a[0] = x` |
| `16(%rsp)` | `s.a[1] = y` |
| `24(%rsp)` | `s.p = &z` |

`process` 通过这些栈偏移将字段读入寄存器。访问 `*s.p` 时，还需要先从 `24(%rsp)` 读取指针，再通过该指针访问 `z`。

**D. `process` 如何设置返回结构体的字段**

`process` 从栈中取得 `s.a[0]`、`s.a[1]` 和 `s.p`，并解引用 `s.p` 得到 `z`，随后通过隐藏返回指针写入：

```c
r.b[0] = s.a[1];   // y
r.b[1] = s.a[0];   // x
r.q = *s.p;       // z
```

以 `%rdi` 保存的返回空间地址为基准，三个字段分别写入偏移 0、8、16。由于这个地址是 `R + 64`，写入的位置实际属于 `eval` 已预留的栈空间。`process` 返回时还将该地址放入 `%rax`。

**E. 返回后的栈布局及 `eval` 对 `r` 的访问**

`process` 返回后，`eval` 的 `%rsp` 恢复为 `R`。栈上原有的 `s` 和 `z` 仍位于 A 中的位置，原先预留的返回空间现在包含：

| 相对 `R` 的偏移（字节） | 内容 |
| ---: | --- |
| 64～71 | `r.b[0] = y` |
| 72～79 | `r.b[1] = x` |
| 80～87 | `r.q = z` |

`eval` 通过 `%rsp` 加固定偏移访问这三个字段，将它们相加：

```asm
movq 64(%rsp), %rax   # r.b[0]
addq 72(%rsp), %rax   # 加上 r.b[1]
addq 80(%rsp), %rax   # 加上 r.q
```

因此 `eval` 的返回值是 `x + y + z`。

**F. 传递和返回结构体的一般方式**

本题中的结构体参数 `s` 以值传递，其内容放在调用者栈帧的参数区域，被调用者通过栈偏移读取。对于这里的 24 字节返回结构体，调用者先分配结果空间，再通过 `%rdi` 传入隐藏返回指针；被调用者把各字段写入该空间，并在 `%rax` 中返回这个空间的起始地址。C 语言层面的返回值仍然是结构体，隐藏指针是汇编层面的实现方式。

结构体的传递和返回方式取决于调用约定、结构体大小和字段类型；较小的结构体也可能通过寄存器传递或返回。

### 3.68

本题需要根据成员偏移推断结构体中的数组尺寸。在题目的 x86-64 环境下，`char`、`short`、`int`、`long` 的大小分别是 1、2、4、8 字节，对齐要求也分别是 1、2、4、8 字节。数组元素连续存储，结构体则会在成员之间插入必要的填充，使下一成员的起始地址满足对齐要求。

题目中的结构体为：

```c
typedef struct {
    int x[A][B];
    long y;
} str1;

typedef struct {
    char array[B];
    int t;
    short s[A];
    long u;
} str2;
```

首先，汇编将计算结果保存到 `184(%rdi)`，对应 `p->y = v1 + v2`。因此 `y` 的偏移是 184，前面的 `x` 数组与填充合计占 184 字节。数组本身占 `4*A*B` 字节，`y` 必须按 8 字节对齐，所以：

$$
176<4AB\le184.
$$

由此得到 `AB = 45` 或 `AB = 46`，分别对应数组占 180 字节、填充 4 字节，或数组占 184 字节、无需填充。

接着，`movslq 8(%rsi), %rax` 从偏移 8 读取 `q->t`，并将 32 位有符号 `int` 扩展为 64 位。`array[B]` 从偏移 0 开始，占 `B` 字节；`t` 按 4 字节对齐，因此：

$$
4<B\le8,
$$

即 `5 <= B <= 8`。如果 `B <= 4`，`t` 会出现在偏移 4 或更早的位置，而不会位于偏移 8。

最后，`addq 32(%rsi), %rax` 从偏移 32 读取 `q->u`。`t` 占据偏移 8～11，因此 `s[A]` 从偏移 12 开始，占 `2*A` 字节。`u` 按 8 字节对齐，要使其位于偏移 32，必须满足：

$$
24<12+2A\le32,
$$

即 `7 <= A <= 10`。

综合 `AB` 的两个候选值及 `A`、`B` 的范围，`46 = 2*23` 无法满足上述范围，而 `45 = 9*5` 满足全部条件，因此：

$$
A=9,\qquad B=5.
$$

代入后，两个结构体的实际布局如下：

| 结构体 | 成员或填充 | 起始偏移（字节） | 大小（字节） |
| --- | --- | ---: | ---: |
| `str1` | `x[9][5]` | 0 | 180 |
| `str1` | 填充 | 180 | 4 |
| `str1` | `y` | 184 | 8 |
| `str2` | `array[5]` | 0 | 5 |
| `str2` | 填充 | 5 | 3 |
| `str2` | `t` | 8 | 4 |
| `str2` | `s[9]` | 12 | 18 |
| `str2` | 填充 | 30 | 2 |
| `str2` | `u` | 32 | 8 |

因此 `sizeof(str1) = 192`，`sizeof(str2) = 40`，成员偏移与汇编一致。
