# ICS 作业整理

## 第 4 讲作业题

### 3.58

根据汇编代码，`subq %rdx, %rsi` 计算的是 `y - z`。随后将它与 `x` 相乘，并根据 `y - z` 的最低位生成全 `0` 或全 `1` 的掩码：

```c
#include <stdio.h>

long decode2(long x, long y, long z) {
    long t = y - z;
    long mask = -(t & 1L);
    return (x * t) ^ mask;
}

int main(void) {
    long x, y, z;
    scanf("%ld %ld %ld", &x, &y, &z);
    printf("%ld\n", decode2(x, y, z));

    return 0;
}
```

其中，汇编中的

```asm
salq $63, %rax
sarq $63, %rax
```

会将 `t` 的最低位扩展到整个寄存器。因此 `t` 为偶数时 `mask` 为 `0`，`t` 为奇数时 `mask` 为 `-1`。

### 3.59

```c
#include <stdint.h>

typedef __int128 int128_t;

void store_prod(int128_t *dest, int64_t x, int64_t y) {
    *dest = x * (int128_t)y;
}
```

令 $M=2^{64}$，$u_x$、$u_y$ 分别表示 `x`、`y` 的 64 位位模式按无符号数解释后的值，并令

$$
s_x=x\mathbin{>>}63,\qquad s_y=y\mathbin{>>}63,
$$

其中 $s_x,s_y$ 的值为 $0$ 或 $-1$。于是原来的有符号数可以表示为

$$
x=u_x+Ms_x,\qquad y=u_y+Ms_y.
$$

两数相乘得到

$$
xy=u_xu_y+M(s_xu_y+s_yu_x)+M^2s_xs_y.
$$

结果只保留 128 位，相当于对 $M^2=2^{128}$ 取模，因此最后一项 $M^2s_xs_y$ 可以省略。汇编代码先计算修正项，再将它加到无符号乘积的高 64 位：

```asm
movq  %rdx, %rax       # rax = uy
cqto                   # rdx = sy
movq  %rsi, %rcx
sarq  $63, %rcx        # rcx = sx
imulq %rax, %rcx       # rcx = sx * uy（低 64 位）
imulq %rsi, %rdx       # rdx = sy * ux（低 64 位）
addq  %rdx, %rcx       # rcx = sx*uy + sy*ux
mulq  %rsi             # rdx:rax = ux * uy
addq  %rcx, %rdx       # 将符号修正项加到乘积的高 64 位
movq  %rax, (%rdi)     # 保存低 64 位
movq  %rdx, 8(%rdi)    # 保存高 64 位
```

双操作数 `imulq` 只保留乘积的低 64 位，因此在模 $2^{64}$ 的意义下，可以用它计算公式中的两个修正项。`mulq` 产生的低 64 位对有符号乘法和无符号乘法都相同；高 64 位则需要加上上述修正项。

## 第 5 讲作业题

### 3.60

```c
long loop(long x, int n) {
    long result = 0;
    long mask;
    for (mask = 1; mask != 0; mask <<= n) {
        result |= x & mask;
    }
    return result;
}
```

循环更新表达式必须使用 `mask <<= n` 或 `mask = mask << n`。单独写 `mask << n` 只会计算并丢弃移位结果，使 `mask` 永远为 `1`，从而形成死循环。

### 3.63

```c
long switch_prob(long x, long n) {
    long result = x;
    switch (n) {
    case 60:
    case 62:
        result = 8 * x;
        break;
    case 63:
        result = x >> 3;
        break;
    case 64:
        x = (x << 4) - x;
        __attribute__((fallthrough));
    case 65:
        x *= x;
        __attribute__((fallthrough));
    default:
        result = x + 75;
    }
    return result;
}
```

汇编先将 `n` 减去 60，并检查所得的无符号下标是否超过 5：

```asm
subq $0x3c, %rsi
cmpq $5, %rsi
ja   0x4005c3
jmpq *0x4006f8(,%rsi,8)
```

因此跳转表处理的范围是 $60\le n\le65$。表中每项是一个 8 字节的目标地址，表项地址为

$$
0x4006f8+(n-60)\times8.
$$

| `n` | 下标 | 跳转目标 | 对应操作 |
| ---: | ---: | ---: | --- |
| 60 | 0 | `0x4005a1` | `result = 8 * x` |
| 61 | 1 | `0x4005c3` | 进入 `default` |
| 62 | 2 | `0x4005a1` | 与 `case 60` 共用代码 |
| 63 | 3 | `0x4005aa` | `result = x >> 3` |
| 64 | 4 | `0x4005b2` | 先令 `x = 15 * x`，再向下穿透 |
| 65 | 5 | `0x4005bf` | 先令 `x = x * x`，再向下穿透 |

`case 64` 后没有跳转或返回，因此继续执行 `case 65`；`case 65` 后也没有跳转或返回，因此继续执行 `default`。所以 `n=64` 时结果为 $(15x)^2+75$，`n=65` 时结果为 $x^2+75$。
