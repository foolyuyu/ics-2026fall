# ICS 作业整理

## 第 11 讲作业题

### 4.57

**A. 加入加载转发后的加载/使用冒险检测条件**

原来的 PIPE 在执行阶段的加载指令与译码阶段指令之间存在下列相关时暂停：

```hcl
E_icode in { IMRMOVQ, IPOPQ } &&
E_dstM in { d_srcA, d_srcB }
```

加入加载转发后，若后一条指令是 `rmmovq` 或 `pushq`，且加载结果只用作写入内存的数据，就不需要暂停。此时前一条指令处于访存阶段，后一条处于执行阶段，可以将 `m_valM` 转发到流水线寄存器 M 的 `valA` 字段，供后一条指令在下一周期写入内存。

若加载结果用于后一条指令的执行阶段运算或地址计算，则仍然需要暂停。因此，新的检测条件为：

```hcl
bool load_use =
    E_icode in { IMRMOVQ, IPOPQ } &&
    (
        E_dstM == d_srcB ||
        (
            E_dstM == d_srcA &&
            !(D_icode in { IRMMOVQ, IPUSHQ })
        )
    );
```

其中，`E_dstM` 是执行阶段加载指令的目的寄存器，`d_srcA`、`d_srcB` 是译码阶段指令的源寄存器。

- `E_dstM == d_srcB`：加载结果参与 ALU 运算或地址计算，执行阶段就要使用，仍需暂停。
- `E_dstM == d_srcA`，且后一条不是 `rmmovq` 或 `pushq`：仍按加载/使用冒险处理。
- 后一条是 `rmmovq` 或 `pushq`，且只有 `d_srcA` 依赖加载结果：待存数据到访存阶段才使用，可通过加载转发消除暂停。

例如：

| 相邻指令 | 是否暂停 | 原因 |
| --- | --- | --- |
| `mrmovq 0(%rcx), %rdx`；`pushq %rdx` | 否 | `%rdx` 仅作为待写入内存的数据 |
| `popq %rdx`；`rmmovq %rax, 0(%rdx)` | 是 | `%rdx` 用于计算写内存的地址 |
| `mrmovq 0(%rcx), %rdx`；`rmmovq %rdx, 0(%rdx)` | 是 | `%rdx` 同时作为数据和地址基址，`d_srcB` 的依赖仍需暂停 |

因此，不能直接排除所有后接 `rmmovq`、`pushq` 的情况；只有它们的待存数据依赖能够通过新增的转发路径解决。

## 第 12 讲作业题

### 6.23

磁盘参数如下：

| 参数 | 数值 |
| --- | --- |
| 转速 | 15,000 RPM |
| 平均寻道时间 | 4 ms |
| 平均每磁道扇区数 | 800 |

访问一个扇区的平均时间由寻道时间、旋转等待时间和传送时间组成：

$$
T_{\text{access}}
=T_{\text{avg seek}}+T_{\text{avg rotation}}+T_{\text{transfer}}.
$$

旋转一圈所需的时间为：

$$
T_{\text{rev}}=\frac{60\times1000}{15000}=4\text{ ms}.
$$

目标扇区相对于磁头的位置近似均匀分布，因此平均旋转等待时间为半圈：

$$
T_{\text{avg rotation}}=\frac{T_{\text{rev}}}{2}=2\text{ ms}.
$$

每圈平均经过 800 个扇区，传送一个扇区需要：

$$
T_{\text{transfer}}=\frac{T_{\text{rev}}}{800}
=\frac{4}{800}=0.005\text{ ms}.
$$

所以平均访问时间为：

$$
\boxed{T_{\text{access}}=4+2+0.005=6.005\text{ ms}.}
$$

### 6.24

文件大小为 2 MB，逻辑块大小为 512 字节。磁盘参数如下：

| 参数 | 数值 |
| --- | --- |
| 转速 | 15,000 RPM |
| 平均寻道时间 | 4 ms |
| 平均每磁道扇区数 | 1,000 |
| 盘面数 | 8 |
| 扇区大小 | 512 字节 |

一个逻辑块对应一个扇区，估算时取文件约含 $N\approx4000$ 个逻辑块。

旋转周期、平均旋转等待时间及单个扇区的传送时间分别为：

$$
T_{\text{rev}}=\frac{60\times1000}{15000}=4\text{ ms},
$$

$$
T_{\text{avg rotation}}=\frac{4}{2}=2\text{ ms},
\qquad
T_{\text{sector}}=\frac{4}{1000}=0.004\text{ ms}.
$$

**A. 最好情况：逻辑块顺序映射到磁盘扇区**

同一柱面在 8 个盘面上共有约 $8\times1000=8000$ 个扇区，足以存放整个文件。将文件顺序安排在同一柱面的磁道上，忽略磁头切换等开销，只需在读取第一个块前进行一次寻道和旋转等待，之后即可连续传送。

传送约 4000 个扇区相当于旋转 4 圈，所以：

$$
\begin{aligned}
T_{\text{best}}
&\approx T_{\text{avg seek}}+T_{\text{avg rotation}}
  +N T_{\text{sector}}\\
&\approx 4+2+4000\times0.004\\
&=\boxed{22\text{ ms}.}
\end{aligned}
$$

8 个盘面用于保证这些块可以安排在同一柱面；题目没有假设 8 个磁头并行传送数据，因此不能再将传送时间除以 8。

**B. 随机情况：逻辑块随机映射到磁盘扇区**

虽然程序按逻辑块顺序读取文件，但相邻逻辑块可能位于不同的物理位置。近似认为每读取一个块，都需要重新寻道并等待目标扇区转到磁头下方。

每个块的平均读取时间包括寻道、旋转等待和扇区传送时间，因此总时间为：

$$
\begin{aligned}
T_{\text{random}}
&\approx N\left(T_{\text{avg seek}}+T_{\text{avg rotation}}+T_{\text{sector}}\right)\\
&\approx4000\times(4+2+0.004)\\
&=24016\text{ ms}\\
&\approx\boxed{24\text{ s}.}
\end{aligned}
$$

顺序布局只需定位一次，而随机布局几乎每个块都要重新定位，因此两者相差约三个数量级。
